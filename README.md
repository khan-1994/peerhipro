# PeerhiPro — شجرہ

Offline bilingual (Urdu / English) family tree web app.

## Live site
Enable GitHub Pages (Settings → Pages → Deploy from branch `main` / root), then open:

**https://khan-1994.github.io/peerhipro/**

## Features
- Father-line family tree
- LocalStorage (data on your device)
- Export / Import JSON
- Spouse, photo, notes, age
- Zoom, pan, print, save image
- Relation finder
- Mobile-friendly

## Backup
Use **More → Export JSON** and keep the file safe.

To share your filled tree with family, send them the exported JSON; they can Import it.
