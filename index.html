🌳 PeerhiPro

App file abhi upload nahi hui — is liye full shajra nahi chal raha.

1 minute setup

  1. Yahan click karke PeerhiPro.html file upload karein
  2. Upload se pehle file ka naam app.html rakh dein (ya upload ke baad rename)
  3. Commit changes
  4. Phir Settings → Pages mein:
    Source = Deploy from a branch
    Branch = main / root → Save
  5. 2 minute wait karke yeh page refresh karein

Jab app.html repo mein aa jayegi, yeh page khud app load kar dega.
